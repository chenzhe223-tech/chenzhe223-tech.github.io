# KNOWA 2.0 · P1 科普创作 Studio

## 新增可运行功能
- /studio 独立知识编辑工作台，支持多草稿、300ms 自动保存、手动版本快照（最多15条）。
- /studio?seed=k01 将旧百科词条数据带入本机草稿；原始证据保留，审校状态仍为 source-review-pending。
- 标题/正文/分类/HTTPS证据 URL 校验，来源机构、口径与自查记录。
- 经过格式检查后导出 JSON、1200×1600 PNG；图片正文过长时注明节选。
- 本地草稿导入限制 JSON 150KB，导入后重置自查标记；删除需浏览器确认。
- 与现有首页知识问答、36题、局部地球动效、5次/日 DeepSeek 配额完全隔离。

## 限制与后续
- 草稿仅当前浏览器 localStorage，**不是云存储或同步**。需定期导出 JSON，清缓存会导致数据丢失。
- 编辑者自行勾选核对，不能代表独立事实审校；导出文档明确显示“来源待复核”。
- 未开启公共编辑接口，未连接付费生图模型，不自动发布至公众号或社交平台。
- 正式协作需登录、编辑权限、审核追踪、服务器持久化和内容发布回滚机制，均未完成。
- 浏览器端 Canvas 下载与自动保存需单独进行交互和移动端测试。

## 验收方式
CI: npm run build && npm run check && npm test && git diff --exit-code -- dist/worker.js.
线上 /studio 与 /knowledge 页面、主页导航、费用门禁要再次验收。
