# KNOWA 2.0 P2 · 科普内容创作闭环初版

功能：知识选择 → 科普文章/科学贴图/12秒科普动态图文 → 文件导出 → 浏览器本地导出日志。

技术：复用 `knowa:studio:drafts:v1` 和只读 `/api/knowledge`；无新数据库、无图像或视频模型费用。
文章为源文编辑编排（Markdown/HTML），不会自动补充未经验证事实。
图片为六主题 1080×1440 PNG，整体沿用现有 KNOWA 蓝色。
视频由 HTML Canvas + MediaRecorder 生成四段各3秒、总长12秒 9:16 竖版。编码器依赖浏览器，MP4 若不支持则回退 WebM。可选择用户上传音频（最大25MB）加入视频；未选择则视频无配音。
所有输出带来源机构与“来源待复核”。视频图像为动态图文，不是 AI 生成实景影像，不承诺专业配音；未经检查不得发布为已审核内容。
浏览器本地草稿与导出历史不等于云端资产存储；无登录、无自动发布，删除缓存将丢失草稿。
后续：审校工作流、作品 R2 与元数据持久化、作品列表、社交平台发布适配器、Graphify、Motion Lab、AI 生图/视频（需要单独费用授权）。

验收门槛：npm build/check/test + dist 一致性、线上 3 个入口/无付费回归、浏览器实际导出文章/PNG/视频。凡未测到的环节不得标绿。
