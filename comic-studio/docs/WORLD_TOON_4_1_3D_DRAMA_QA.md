# WORLD/TOON 4.1 · 3D 拟人角色与狗血网红短剧升级记录

日期：2026-11-11。状态：代码提交与静态资源上线检查通过；真人肖像实际生图、真实付费模型生成和微信发布尚未端到端验收。

## 1. 新增风格

在原有 21 种图鉴基础上加入 4 种：电影级 3D 拟人角色、高级 3D 卡通拟人、时尚杂志 3D 图像小说、爆款短剧 3D 漫画。新分类“3D 与数字角色”。新增项仅是视觉规范，未把占位图当成真实模型生成样张。

## 2. 肖像参照与生成 SOP

导演台可先确认本人或肖像权人授权，再上传 PNG/JPEG/WebP 图片，当前设备 IndexedDB 保存原照片并记录 SHA256、服装与容貌说明；照片不会自动发布到公共书架。提供一键导出原照、SHA256、角色设定、3D 画风、定妆要求的 ZIP。ChatGPT 正式工单 ZIP 也会附带已授权的参考原照。

照片保存不等于真实 3D 生图，正式生成应交由具备图像模型的生产 Agent 执行，并先提交作者可核对相似度的角色定妆图。WorkBuddy 自动派单暂不支持私密照片附件传输，故含肖像照片任务会明确阻止此 SOP 自动派单。完整备份/恢复包含经授权的照片。IndexedDB 不应被描述为默认加密存储。

## 3. 狗血网红剧情与 DeepSeek

支持通用、狗血网红爽剧两类；后者包括重生银行富婆、娱乐圈合约恋爱、真假千金逆袭、银行职场网红四个主题及 1–5 级反转强度。选项写入真实 DeepSeek 扩写请求，强制区分原创虚构故事和现实人物的未经证实指控。导演台新增“狗血网红爽剧”结构，DeepSeek 使用既有 Cloudflare Secret，不要求重复输入密钥。
