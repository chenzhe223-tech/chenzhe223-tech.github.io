## 本次代码变更

### P0 · 三入口、一个向导
- 首页突出 **热点改编 / 一句话创作 / 自主创作**，复用既有热点发现、AI 简报、选题池和草稿项目模型。
- 本次新项目带 `creationPath`；原创与一句话项目不冒充真实新闻，不要求虚构新闻来源。
- 七步为 **故事方案 → 角色设定 → 剧情分镜 → 视觉风格 → 正式生成 → 审阅精修 → 导出发布**，提供前后导航、返回编辑和持久保存时间。
- 保留原有工作台高级入口，旧数据 `APP_KEY='davylab-comic-press-v1'` 不改，避免无授权迁移/覆盖。

### P1 · Character Bible
- 角色库在原有稳定 ID、作品级别名基础上增加年龄、职业、性别及自定义身份。
- 新 AI 人物草稿标记待作者确认；可从角色库引用，创建作品级独立覆盖字段。
- 作者确认后锁定作品级角色快照：角色 ID、原名/漫画名、版本、外貌、服装、性格、身份、视觉参考及版权核验状态。
- 承接角色库的后续变更仅影响新版本，不自动重写已经锁定的作品。
- 完整角色快照和逐格角色版本信息进入原有 GitHub 制作任务。
- 仅关联角色但未锁定的新 V4 工单不得派单；旧作继续保持原有协议兼容。

### P2 · 生产防降质
- 分镜提示词优先引用本作品已锁定角色快照，避免角色库未来修改导致角色漂移。
- 新 V4 项目禁止绕道旧 768×1024 测试生图系统；不再以低清/占位图冒充正式作品。
- 沿用原来的双轨、真实首图/作者定妆审批、画风锁定和分镜修订流程。
- **未开启原生收费/可能计费的 AI 生图功能**，未用真实外部模型完成 9 格生产，因而无法声明 AI 成图质量验收完成。

### P3 · 下载、QA 与发表边界
- 复用现有 `worldtoon-v3-import.js` 的 ZIP 导入、PNG 解码及尺寸和 SHA256 检查。
- 复用原有 `comic-engine.js`、GitHub 交付仓库的 QA、WorkBuddy 队列和回执机制。
- 导出文件存在、GitHub QA、作者授权、WorkBuddy 实际发表及正式书架归档必须分别核验；不能以本地 ZIP 或模拟状态冒充完成。
- 目前尚未真实生成 V4 完整高清样本，也未完成 Cloudflare 正式部署/线上新版本复核。
