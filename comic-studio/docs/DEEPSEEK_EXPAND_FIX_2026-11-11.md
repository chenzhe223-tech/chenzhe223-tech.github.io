# WORLD/TOON · DeepSeek 扩写按钮故障修复记录

Date: 2026-11-11 · Release: 4.0.3 · Status: **静态资源上线与模拟回归通过；真实付费模型调用未执行**

## 复现问题

- 用户在漫画创作工作台点击「DeepSeek 扩写并推荐篇幅」后，没有明显持续反馈。
- 原 `archive.js` 的 `wtArchiveApi()` 对该模型接口固定 15 秒超时，但 Cloudflare Worker 对 DeepSeek 上游允许 55 秒；正常的较长推理会提前被客户端中断。
- 旧逻辑依赖浏览器原生 `confirm()` 和仅持续 3.2 秒的 toast，超时或登录/额度错误容易被认为按钮无效。
- `workflow-v4.js` 的只读模型状态探测成功后会重渲染完整页面，可能丢失正在编辑的构思与费用确认状态。

## 已修复

1. `archive.js` 对 `deepseek-expand` 专用 75 秒客户端超时，其他归档 API 继续保留已有策略；超时显示可理解的错误，不会自动重试或自动重复扣费。
2. `worldtoon-v3.js` 点击扩写先打开页面内的明确费用确认区；用户再次确认后才真正发送请求。
3. 明确持久的执行状态：确认费用、生成中、成功、失败；失败保留已有分镜及构思，按钮恢复可再次发起。
4. 异步请求具备防重复处理；只有带 `verified_model_response` 标记和完整分镜的真实返回才写入草稿并进入创意导演台。
5. 模型只读状态回调仅更新状态文字，不再重绘/清空创作表单。
6. 更新静态资源版本和 Service Worker 缓存键为 4.0.3。
7. 加入 `worldtoon-deepseek-smoke.cjs` CI 回归测试；保留 3.0 / 4.0 其他烟雾测试。

## 证据与验收

- 两份旧版回归脚本均通过隔离执行测试。
- 新增点击流测试：首次点击 0 次模型请求；取消 0 次；确认后 1 次；成功写入 4 格并转导演台；失败保留原 9 格且显示明确错误，测试通过。
- 外部站点读取：Worker 的根页面、`worldtoon-v3.js?v=4.0.3`、`archive.js?v=4.0.3` 均返回 HTTP 200；新按钮/超时代码在响应中可核对。
- Cloudflare Secret 元数据读取显示 `WORLDTOON_DEEPSEEK_API_KEY` 已配置（未读取或暴露密钥值）。
- **未执行**真实计费 DeepSeek 扩写（用户尚未通过新版页面进行该次费用确认），因此不声称端到端真实推理或 GitHub Actions 云端运行已通过。

## 实际用户验收

打开 https://worldtoon.chenzhe223.workers.dev/#/workspace ，进入 AI 编剧步骤，输入或保留一句话构思：

1. 点击「DeepSeek 扩写并推荐篇幅」：应出现页面内费用确认区与提示信息。
2. 点击「确认并开始生成」：应显示执行中状态，完成后进入导演台。
3. 若网络、登录、额度、模型格式异常，页面内应显示原因，原有分镜不被无故清空。
4. 需要时按 Ctrl+F5 清理旧版浏览器缓存。实际调用可能产生费用，未授权不得自动运行。
