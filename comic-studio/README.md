## 产品业务流程

1. 发现：集采全球热点，原文追溯、日期核验、跨来源合并去重。
2. 选题：影响 35%、热度 25%、重要性 25%、叙事潜力 15%（拟议权重，可调整）。
3. 改编：提炼已核实事实；将创作性内容与事实分层；使用架空角色、设定和原创剧情。
4. 剧本：角色圣经、故事主线、6/9/12 格分镜、对白与旁白。
5. 生图：角色一致性参考图、单格精修、多格拼版、手机阅读与公众号导出。
6. 审核：事实/版权/隐私/名誉/来源/敏感内容复核，人工批准后发布。
7. 发布：期刊管理、长图、PDF、逐格 PNG、公众号贴图包、网站公开阅读。

## 里程碑

### P1. Hotspot Intake（计划中）
- 首先复用 DAVYLAB AI Radar 和公开 RSS / 新闻 API / Firecrawl，在时间窗口内集采热点。
- 记录来源链接、发布时间、事件发生时间、重复簇和可靠度；不得把聚合摘要当原文。
- 建立原创虚构题材与真实事件改编题材双轨工作流。

### P2. Comic Engine（计划中）
- LLM 编剧：人物动机、冲突升级、台词、结尾、改编风险检测。
- 图像生成接入：统一人物设定、服饰、场景、画风与种子参考；失败重绘。
- 图片与文字分层，避免大模型直接在画面渲染长段中文对白。
- 实测 9 张独立画面的角色一致性、可读性和手机端呈现。

### P3. Production and Distribution（计划中）
- 完整账号登录、多端同步；可评估 Cloudflare D1 + R2 或已有 Supabase 新加坡资源。
- 支持漫画集模板、出版社式封面、历史版本、审批、导出 ZIP/PNG/PDF、公众号适配。
- 后台任务与限额、失败重试、成本监控；只有获授权后才启用收费 AI / 存储服务。

## 内容守则

- 不得仅以替换姓名或“纯属虚构”标签规避名誉与隐私风险。
- 未证实的犯罪或丑闻指控，不得通过可识别真人替身暗示为事实。
- 涉及真人真实事件必须有来源引用，清晰区分新闻事实、作者评论和原创虚构。
- 不以自动抓取方式复制受版权保护的完整新闻文章或漫画图。
- 自动发布必须经过明确授权并保留审核日志。
