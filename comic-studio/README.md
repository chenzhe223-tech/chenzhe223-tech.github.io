# WORLD/TOON · By DAVYLAB

独立的全球热点漫画创作、出版与管理平台。网站地址保持 `https://worldtoon.chenzhe223.workers.dev/`，代码放入 `chenzhe223-tech/chenzhe223-tech.github.io` 仓库的 `comic-studio/` 目录。

## v1.0 实际实现

- **漫画书架**：多作品增删、复制、归档、回收站、作品搜索、状态记录
- **热点素材**：手动记录题材、分类、链接、事实核验状态、三维评分及优先度
- **五阶段创作台**：选题与来源、虚构改编设定、九格分镜、逐格导入视觉、人工审核
- **九格漫画阅读器**：翻页、缩略图、键盘左右方向键、移动端适配
- **出版素材**：封面 PNG (1080×1440)、九张漫画图 ZIP、含九格图片的独立静态 HTML 网站 ZIP（可在浏览器打印存成 PDF）
- **项目与工作区**：JSON 项目导出、完整 ZIP 备份/导入（含用户图片）、本地自动保存、IndexedDB 图像存储
- **旧版兼容**：首次运行自动识别 `davylab_worldtoon_v01` 并尝试迁移旧作品和图片；旧版原记录保留
- **内容安全**：真实来源核对、分离事实与虚构、人工审核门禁；任何“已发布”状态仅为本地记录，不会自动向微信/小红书推送
- 首期《霸总的小爱情》九张独立图像与封面已集成；为原创虚构示例，**不是现实新闻核验结果**。

## 本地运行

```bash
cd comic-studio
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000
```

本产品使用纯静态 HTML/CSS/JS，不依赖本地 npm 构建工具。图片存于 `assets/`。用户编辑信息存于浏览器 localStorage，上传图片使用 IndexedDB。清除浏览器数据前使用“数据管理 → 导出完整工作区 ZIP”。

## Cloudflare Worker 部署

生产 Worker `worldtoon` 固定代理 GitHub 仓库 `main/comic-studio/` 下的允许静态资源；Worker 源码见 `worker.js`。更新时应先提交资源至 GitHub，再发布 Worker，最后验证 `/health`、`/`、`/app.js`、九张图片与真实浏览器运行。

## 创作边界

仅改名或标注“纯属虚构”不足以规避对真人的暗示性指控。不得把未经验证的违法、私生活和政治交易指控改写成可识别真人的漫画事实。事件、评论和艺术虚构应清晰区分，新闻原文和第三方图片尊重版权与授权。
