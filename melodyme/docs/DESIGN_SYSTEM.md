# MelodyMe 视觉识别与 UI 设计系统 v0.1

## 品牌基调
温暖、克制、真实、有电影感。避免霓虹渐变、过度拟物、装饰性光效和泛化的“AI 科技风”。视觉主角始终是用户的记忆，而不是 AI 本身。

## 品牌表达
- 主标语：每一首歌，都是你走过的路。
- 辅助文案：用音乐，记录更真实的你。
- 品牌语气：像懂音乐的朋友；自然、真诚、不说教、不诊断情绪。
- 工作名称 MelodyMe 尚未进行商标或域名核验。

## 色彩令牌
- Ink / Deep Navy: #172B42 — 主文字、导航、深色内容区。
- Paper / Warm White: #F5F2EC — 页面背景。
- Surface: #FFFDFA — 卡片、表单。
- Lilac: #9588C9 — 轻量强调与选中状态。
- Rose: #E8B0BD — 柔和情绪辅助色。
- Sand: #D1BDA4 — 中性色辅助。
- Muted: #78818A — 次级文字。
- Border: #DED9D0 — 分隔线和边框。
- Error: #A63B42 — 错误状态（不得只用颜色传达）。
- Success: #2F6D58 — 成功状态。

## 字体与排版
- UI 正文：系统无衬线字体栈，确保中文可读。
- 品牌/故事标题：Georgia/可用衬线字体栈作为概念方案；生产版需明确授权与跨平台回退。
- 页面标题 32–54px 响应式；正文 14–16px；辅助文字 11–13px。
- 行高：正文 1.55–1.7；标题 1.1–1.25。
- 长文最大阅读宽度约 65–72 字符，避免铺满桌面视口。

## 布局与组件
- 最大内容宽度：1180px；桌面双栏，移动端单栏。
- 页面边距：桌面 24–32px，移动端 16px。
- 间距基础：4px；常用 8/12/16/24/32/48/64px。
- 卡片圆角 16–24px；输入与按钮圆角 12px / pill。
- 边框 1px；阴影仅用于浮层，卡片默认靠留白和边框区分。
- 主按钮深海军蓝底白字；次按钮透明底细边框。
- 点击目标建议至少 44×44 CSS px。
- 交互反馈包含 focus-visible、disabled、loading、success、error、empty。
- 动效短而轻；遵循 prefers-reduced-motion。

## 主要页面
1. Discover：品牌主张、轻量示例和清晰创作入口。
2. Create Memory：歌曲（可选）、一句回忆、可选年份和情绪标签。
3. Artwork Preview：海报、故事文案可编辑，保存/复制分享。
4. My Music Life：按时间排序的私人记忆时间线。
5. Future Share Preview：在公开前展示内容快照与可见范围；当前原型不实现公开分享。

## 组件约定
- MemoryCard：封面、标题、年份、情绪标签、权限状态。
- TimelineEntry：时间、标题、短摘要；支持编辑/删除。
- StoryEditor：用户可编辑文本，不把模型输出锁定。
- PosterPreview：使用 HTML 排版真实文字；不依赖图像模型直接绘制中文。
- PrivacyLabel：始终明确“仅自己可见/公开”等权限状态。
- GenerationStatus：idle / queued / running / succeeded / failed / cancelled。
- EmptyState：解释价值并提供单一下一步操作。
- ErrorState：说明发生什么、是否保留输入、可执行的恢复操作。

## 可访问性
- 语义化 HTML、表单 label、键盘可操作。
- 焦点可见，颜色对比需在正式实现中验证 WCAG AA。
- 不仅依靠颜色表达错误/成功/选中。
- 图像提供有意义的 alt；装饰图标隐藏于辅助技术。
- 减少动效偏好有效。
- 手机端不能依赖 hover 才能访问功能。

## 当前限制
本规范用于第一阶段原型与后续工程实施。尚无经过商标审查的最终 Logo 矢量文件、字体授权清单或正式设计工具文件。
