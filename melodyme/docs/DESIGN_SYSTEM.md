# MelodyMe 视觉与交互设计系统 v0.2

## 品牌基调
温暖、克制、真实、有电影感。用户的记忆是主角；地图用于组织探索，不是装饰背景。避免高饱和渐变、霓虹科技风和通用社交 feed。

## 页面与交互模型
- 首屏是音乐人生地图、品牌主张和「开始探索」。
- 地图包含四个可点击节点：唤起记忆、找到感觉、发现音乐、收获作品。
- 节点支持未探索、当前、已完成、已跳过状态；允许回访。
- 每个节点只呈现一个核心问题；允许跳过，非必要字段不强制。
- 一句话故事是唯一主要自由输入。歌曲和艺人是可选线索；不要求用户填专辑、年份、封面。
- 过程中的阶段预览显示已获得线索与正在形成的作品。
- 作品页提供海报预览、故事文案、朋友圈文案、保存、复制与 SVG 导出。
- 我的作品只显示当前设备本地保存内容，不能标记为云端备份或公开作品。

## 组件规范
- JourneyMap：可操作的 SVG 地图；节点需对应真实状态与行为。
- JourneyNode：当前、完成、跳过状态，不只依赖颜色表达。
- StoryPrompt：一句话输入与可选快捷方向。
- ChoiceChip：可多选，清晰呈现 aria-pressed。
- MusicClue：明确用户输入/待核验来源，不用随机图片冒充专辑封面。
- ArtworkPreview：HTML/SVG 真实排版，中文不交给图像模型直接绘制。
- PrivacyNotice：清晰标注本地保存与未接入服务。
- EmptyState / ErrorState：解释状态并提供下一步。

## 响应式与可访问性
- 手机优先；窄屏单列，节点按钮至少 44px 触控高度。
- 不允许横向溢出；支持键盘焦点、语义化按钮与减少动效偏好。
- 重要状态使用文字或图标辅助，不仅依赖颜色。
- 长文可读宽度受控，标题和正文保持清晰层级。

## 当前限制
此版本是静态 HTML/CSS/JS 交互原型。真实 AI、音乐元数据 API、专辑封面、Shazam 官方跳转可用性、账号、云同步与公开分享均未完成或未验证。
