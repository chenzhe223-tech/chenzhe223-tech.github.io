# MelodyMe 工程规则

本文件仅约束 `melodyme/` 项目。开发或维护 MelodyMe 时，先阅读：

- `README.md`：当前产品范围与已知限制。
- `docs/ARCHITECTURE.md`：前端、Worker 与第三方服务边界。
- `docs/DESIGN_SYSTEM.md`：界面视觉与交互规范。
- `docs/QA_PLAN.md`：验证要求。

## 技能路由

按任务读取对应本地技能；它们是供 Codex、WorkBuddy 等开发代理使用的工程规范，不是浏览器运行时插件：

- UI、布局、移动端、无障碍、交互状态或视觉验收：`skills/melodyme-frontend/SKILL.md`
- 音频预览、HTMLAudioElement、媒体事件、错误恢复或播放行为：`skills/melodyme-audio-engineering/SKILL.md`
- Apple MusicKit、iTunes Search、目录/播放权限、将来原生 iOS 集成：`skills/melodyme-music-platform/SKILL.md`

## MelodyMe 不可突破的产品边界

1. 当前应用使用 iTunes Search 返回真实歌曲目录与可用的短试听 URL；试听必须由用户主动触发，不得伪装成完整歌曲播放。
2. 不得声称拥有 Apple Music 完整曲库播放权限，不得绕过 DRM、登录、订阅或地区限制。
3. MusicKit 只有在产品确实需要 Apple Music 会员曲库且具备正确的开发者配置、用户授权和合规流程时才可引入；不能为了“集成 Skill”而增加运行时依赖。
4. 不引入未经授权的音乐源、抓取、代理播放或隐藏自动播放。
5. 当前主创作流程为“四座城市 + 一首歌 → 动态音乐地图”。旧四站故事/海报流程仅作为兼容旧作品的遗留能力，不应再作为默认新建流程。UI 优先移动端，避免为了视觉优化删除旧作品数据。
6. 所有音乐元数据必须来自真实响应；不确定字段应省略或明确标注，禁止编造。
7. 修改后应运行可用的自动化测试，并记录“已修改、已测试、已部署、真实线上验收”四种不同状态；不得将部署成功等同于端到端验收通过。

## 单海报强制规则（最高优先级）

- 每次结果页有且仅有一个完整可见的主海报；AI 图片必须嵌入现有 `#poster`，禁止在其下方另建第二张封面/预览卡片。
- `#aiCoverFrame` 与 `#aiCoverImage` 只能作为唯一 `#poster` 内部的背景图层，不能独立形成第二张海报。
- 初次生成、重新生成、风格/配色/歌曲切换、生成失败、刷新及恢复作品，均复用原有容器；不得追加新的海报 DOM。
- 下载、重新生成、分享和生成说明放在唯一海报模块外侧作为操作控件，不重复展示海报图片。
- 禁止同时将同一张图片设置到 `#aiCoverImage` 和 `#poster` 的 CSS background，避免同图双层渲染。
- 验收必须检查实际 DOM：`#results #poster` 数量为 1，`#aiCoverFrame` 必须是 `#poster` 的后代，海报模块之外不得存在第二张完整海报图。
- 连续重新生成 5 次、切换至少 3 种风格、失败后重试、刷新和恢复作品均不得出现第二张主海报；保留下载、分享、图片技术检查与失败恢复能力。

## 四城音乐地图（当前主产品方向）

- 新建旅程必须进入四城音乐地图工作台，用户输入四座不同城市与一首歌；不能再默认展示“唤起记忆 / 找到感觉 / 发现音乐 / 收获作品”四节点表单。
- 四城坐标必须由 Cloudflare Worker 服务端调用高德地图 Web 服务地理编码接口核验。高德 REST Key 只能作为 Worker Secret `AMAP_REST_KEY` 保存，绝不写入前端、仓库或日志。
- 未配置高德 Key、城市解析失败或返回重复坐标时，明确报错，不得用猜测坐标、硬编码样例或其他地图源伪装为高德结果。
- 歌曲使用现有 Worker `searchMusic` action 和真实 iTunes Search 目录；歌名、歌手、封面与试听 URL 必须来自目录响应。仅在有 `previewUrl` 时提供试听，不自动播放、不提供完整歌曲流。
- 地图按真实经纬度有序呈现四个城市，路线是记忆顺序的视觉连线，不得描述为道路导航路线或真实驾车路径。
- 播放旅程时，路线动画应与用户主动启动的试听片段同步；暂停/继续应尽可能对齐播放位置。
- 城市、已核验坐标和所选歌曲应能本地保存并恢复；下载 SVG 必须内嵌必要样式，避免下载后丢失路线、标签和标记样式。
- 自动化测试覆盖四城字段、真实地理编码 action、音乐目录匹配、试听 URL、四个地图标记、重复城市校验、保存/恢复和手机端无横向溢出。
- 目前不宣称导出带音轨 MP4；当前交付是可播放、路线动画同步的网页地图和可下载 SVG 静态地图。
