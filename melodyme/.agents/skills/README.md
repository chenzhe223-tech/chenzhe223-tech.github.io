# MelodyMe — GSAP Skills

This directory contains the eight official GreenSock GSAP Agent Skills copied from [greensock/gsap-skills](https://github.com/greensock/gsap-skills) for project-local Codex use.

- gsap-core
- gsap-timeline
- gsap-scrolltrigger
- gsap-plugins
- gsap-utils
- gsap-react
- gsap-performance
- gsap-frameworks

Read the relevant `SKILL.md` before implementing animation work. MelodyMe is currently a static HTML/JavaScript app; React and other framework skills are included for future reference but do not justify migrating the app to a framework. Runtime enhancement lives in `../gsap-motion.js`. GSAP must remain progressive enhancement and respect the project rules in `../../AGENTS.md`.
