从灵感到公众号草稿

有检查点的工作流，不是点一下就自动发文。每一步都保留真实状态。

01 / DISCOVER

发现与收集

查看 Davy Radar 的真实来源，或记录产品开发中的问题。新闻内容先回到原文核实。

02 / SELECT

判断值不值得写

按读者价值、时效、实操性、差异化和品牌契合度评分。分数只是辅助，不是爆款预测。

03 / CREATE

和 ChatGPT 一起写

生成标题、结构、正文和素材清单。凡涉及事实的数据要核查并留下来源。

04 / REVIEW

准备交给 WorkBuddy

整理文章或贴图素材包。WorkBuddy 保存草稿并检查手机预览；缺图、错字或排版异常时停止。

05 / PUBLISH

你本人决定发布

后台草稿、手机预览和正式发表是三个不同状态。最终发布仍由你本人确认。

06 / LEARN

记录反馈

发布后记录阅读、点赞、在看、转发和真实留言，用结果调整后续选题。

数据与使用边界

为后续跨设备同步和自动化交接预留明确的数据结构。

01 / LOCAL

本机数据

当前版本将增长目标、实验、贴图任务和指标存放在本浏览器 localStorage。更换设备前请导出 JSON。

02 / VERIFY

真实数据优先

阅读、分享、订阅与发布状态需要从真实后台或执行回执核验。未录入时显示空值，不自动生成虚假数字。

03 / HANDOFF

WorkBuddy 交接

本模块记录交接状态，但不会自动下载私有内容包、上传图片或操作公众号。完成后再依据真实回执更新状态。
