# DAVYLAB 公众号平台｜海外观点修复＋全球财经资讯＋财经快报模式

开发 PR：#155 · 2026-11-20 · 独立分支 feat/topic-studio-overseas-finance-20261120

> 注意：本文件描述开发范围和验收清单。不能以代码已提交代替网站已更新，也不能把采集到的线索视为已核实新闻。

## 一、现状和已定位问题
- XNews 主要依赖单一外部编辑索引 `https://xnews.qiaomu.ai/articles.json`，上游不新增文章时本模块实际没有新内容。
- 浏览器普通加载此前使用固定 `?t=v1`，并且 `cache=default`，可能继续展示过期静态快照。
- 同步脚本失败时保留上次有效数据是必要的，但之前未提供清晰、可见的“上游停更”和“缓存回退”区分。
- 现有 A 完整文章 / B 内容策划不适合简短财经快报。只生成提示词，不代表外部 AI 已创建海报或 ZIP。

## 二、海外观点
- 继续保留 XNews 源及原标题、中文短导读和原文 URL。
- 增加 Simon Willison / GitHub AI Blog / Hugging Face 的独立原始 RSS/Atom 公开来源，独立数据文件 `topic-studio/data/overseas-discovery.json`。
- 页面合并去重，不允许把独立来源伪称成 XNews 翻译文章，独立来源不显示“中文阅读”按钮。
- 原索引与独立信息源分别采集、失败隔离；当全失败时红灯并保留历史有效记录。
- 普通加载、手动刷新均使用 no-store 和变动查询参数。展示原始发表日期、最近抓取时间、过期提示。
- GitHub Actions 定时在 **每日 09:25 UTC+8** 采集；计划任务在 main 合并后才会成为正式生产工作流。定时可能被 GitHub 平台延迟，需要检查最新真实运行记录。

## 三、全球财经资讯
- 数据来源：美联储、SEC、ECB、BLS、BEA 等官方公告；CNBC Finance / World public RSS 作为**媒体报道线索**。
- 只采集公开标题、短摘要、URL、来源、时间和来源类型；不抓取全文、付费内容或模拟价格。
- 每日 **10:15 UTC+8** 定时增量更新 `topic-studio/data/finance-discovery.json`，最长30天近期数据，保持有据可查的历史快照，失败不覆盖最后有效数据。
- 页面支持财经分类、搜索、时间和来源展示、一键加入现有选题池，新闻卡片引入 `productionMode=finance`。
- 原文采集即新闻线索，人工或额外可信资料复核后才能写“已核实”。财经媒体报道不得当作公司官方公告。

## 四、财经快报生产（独立 C 模式）
- 保留 A 完整素材生产和 B 内容策划两个现有模式。
- 选择财资讯题默认进入 C；正文 **100～300字**，1个≤26字强标题、1句核心结论、≤100字贴图配文、短朋友圈文案，单位/币种/日期/口径与数据出处明确。
- 海报数量由用户选择1、2、3，逐张生成**独立 1080×1440 PNG**，不可拼版，不可用示意图或提示词冒充成品。
- 六套可选专业风格：国际商业杂志（蓝金）／机构研报（白蓝金）／黑金资本／环球财经蓝白／财经头条红黑／极简科技财经。
- 中文与关键数字需可控排版，严禁凭空制造K线、指数、涨幅；财经资讯非投资建议。
- 外部模型必须真实生成正文、PNG、核查文档及 ZIP，再检查图片尺寸、数据来源、拼版、压缩包可用性。页面仅生成可执行**指令**，不假称自动出图。

## 五、测试及发布门禁
- Python：财经六类离线单测、海外三类离线单测；RSS/Atom、源错误隔离、没有虚构行情、格式与来源。
- Node：六种风格与海报数量边界、原 A/B 模式回归、XNews 合并与 XSS 处理。
- Chromium：桌面1440 / 手机390 的财经卡片→选题池→C 模式→6风格→1~3张参数→切换 A/B 回归，检查手机横向溢出。
- Live：真实财经 RSS 采样显示成功源与失败源，海外原始来源至少有一条真实新线索（采集不等于核实）。
- 生产：CI全部绿、实际首页显示新的财经区并成功读取最新JSON、次日日更工作流实际运行、旧 XNews 及原内容生产不受损。达到门禁并获部署批准后才能合并上线。
- 内容审批：一律 draft；未得到作者 approved，不上传正式微信发表、不推送秘密或未发表稿件至公开仓库。
