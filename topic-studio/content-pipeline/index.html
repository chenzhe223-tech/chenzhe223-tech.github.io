当前自动化边界

以真实回执为准，不以文档代替执行
PUBLIC / STATIC

选题平台与公开档案

公开站点保存平台代码、Davy Radar 公开来源和经过核验的已发文章元数据。浏览器 localStorage 的选题不会自动跨设备同步。

PRIVATE / PACKAGE

未发表内容包

文章、配文、图片、来源说明、SHA-256 清单和 QA 报告保存到私有仓库；通过审批后才生产正式内容包。

WORKBUDDY / DRAFT

草稿与手机预览

WorkBuddy 命令 A 下载、校验并保存草稿，再重新打开检查和手机预览；只有所有检查通过才能继续。

ONE-TIME AUTHORIZATION

正式发表需单独授权

用户在 WorkBuddy 当前会话对指定 package ID 发出命令 B 后，才可正式发表。生产审批不等于发表许可。

推荐操作顺序

每一步都保留可核验状态
01 / PROPOSE

分析并批准提案

ChatGPT 核查原始来源、去重已发内容并提出一个首选方向；用户明确批准制作后才继续。

02 / PRODUCE

生成并验收素材

制作原创图文、图片、来源说明、SHA-256 清单和 QA 报告；未通过验收不交给 WorkBuddy。

03 / COMMAND A

保存草稿并预览

WorkBuddy 从私有仓库下载指定包，校验后录入 DAVYLAB 公众号，保存草稿、重新打开并检查手机预览。

04 / COMMAND B

单次授权后发表

草稿与手机预览确认后，用户对指定 package ID 明确下达发布命令。没有这条命令，流程必须停在草稿。

DAVYLAB · 把想法，做成能用的工具。如果队列状态、草稿或发布链接无法核验，请停止并回报，而不是推测。
