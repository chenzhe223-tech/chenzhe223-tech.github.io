# DAVYLAB Content Studio · 品牌识别系统 1.0

**应用场景：** DAVYLAB 微信公众号选题平台（选题发现、赛道研究、收藏、排期、配图策划、增长实验室）。归属 DAVYLAB 个人品牌，不替换其他产品统一标识。

## 标志创意：Signal → Judgement → Story

- **3 条水平线：** 世界公开资讯、个人实践与选题灵感，汇入编辑工作台。
- **蓝色菱形：** AI 协助整理，作者做出自己的选择和验证。
- **右向推进符号：** 从线索到成稿、验收和最终发布。
- **深海军蓝底：** 专业、可靠、长期内容资产；亮蓝只用作重点操作和选中态。
- 标志没有使用通用的“D 字母渐变”，也没有把“AI 自动创作/发布”作为无需人工审核的承诺。

## 色彩与字体

- **Navy #142B40**：标志、主标题、导览权重
- **Blue #2D78D7**：选中项、按钮、焦点、编辑判断节点
- **Ink #18344C**：文字
- **Paper #F7F9FB**：正文背景
- **Cloud #EAF3FC**：低权重选中/辅助提示
- **Line #DCE6ED**：卡片边框
- **Muted #657E92**：信息元数据

中文优先系统可读黑体；英文使用 Inter / Arial / 系统无衬线。SVG 横向字标包含字体文本，跨系统字形会依设备有所不同；正式网页使用 SVG 主标配浏览器文字，确保高可用与可调整。

## 使用规则

1. Logo 保持原比例，建议周围至少留出标志宽度 1/4 的呼吸空间。
2. 图标小于 24px 时改用主标，不展示小字号口号。禁止拉伸、加渐变或用滤镜变色。
3. 主操作按钮使用亮蓝，正文不使用亮蓝充当整片背景。强调信息/当前来源时可使用海军蓝与浅蓝。
4. 不破坏现有用户设置：仅重新定义品牌相关组件样式，内容本身、数据源、审核流程不变。
5. 在移动端保留真实图形标识，字号与内容优先保证可读性。
6. 公众号文章配图遵循各篇主题视觉策略，**不把当前平台的产品 UI 颜色强加到所有独立文章插图里**。

## 实施位置与边界

- `topic-studio/index.html`：图标、Favicon、侧栏品牌名、顶部路径、首页眉标、底部署名。
- `brand-studio.css`：桌面及手机端侧边栏、选中导航、头部、重要按钮、专题卡片、移动封面符号。
- 这些变化不会启用云端同步，也不会调用微信发表接口。
- 实际完成情况以 GitHub 源码、浏览器加载与 QA 结果为准；只提交源码不等于生产站点及全部屏幕尺寸已通过验收。
