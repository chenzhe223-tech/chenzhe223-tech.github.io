1. 先读取 `keypocket/docs/project-continuity/HANDOFF.md`、`CURRENT_STATUS.md` 和 `PROJECT_CONTEXT.md`。
2. 按需要读取 `DECISIONS.md`、`TASKS.md`、`TEST_AND_ISSUES.md` 和 `CHANGELOG.md`。
3. 核对当前仓库 HEAD、实际代码、CI 结果及 GitHub Pages 部署状态。不要只相信档案或旧聊天。

8. 不将任何真实 API Key、Token、密码或用户密钥数据写入档案。
