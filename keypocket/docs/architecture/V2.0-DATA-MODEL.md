# KeyPocket V2.0 — 数据模型与迁移设计

更新：2026-11-02

## 1. 兼容基线

- 不修改 V1 IndexedDB 数据库名 keypocket-local-v1、对象仓库 vault 与 DB version。
- 保留 V1 sealRecord/openRecord、sealProject/openProject 与 AES-GCM/PBKDF2 密文格式。
- app-v2.js 作为附加运行层加载；系统行使用 kpv2: 前缀并从 V1 业务查询中排除。
- 旧 Supabase 表 keypocket_vault_sync 保留，仅用于首轮迁移读取；V2 不再以整库行作为主同步模型。

## 2. IndexedDB V2 系统行

| 类型 | ID 规则 | 内容 | 加密边界 |
|---|---|---|---|
| 自动检查点 | kpv2:snapshot:autosave:latest | 最近一次完整本地数据与回收站状态 | 外层由本地 AES-GCM 加密，内部记录仍保留 V1 密文 |
| 每日快照 | kpv2:snapshot:daily:YYYY-MM-DD | 当天首次建立的本地状态 | 同上 |
| 月度归档 | kpv2:snapshot:monthly:YYYY-MM | 当月首次建立的本地状态 | 同上 |
| 重要操作 | kpv2:snapshot:milestone:<reason>:<time> | 删除、恢复、导入覆盖前的状态 | 同上 |
| 回收站 | kpv2:trash:<entity-type>:<entity-id> | 原始加密行、删除时间、到期时间、同步版本 | 原记录保持原密文；墓碑元数据保存在本地 |

快照保留：自动检查点 1 个、每日 30 个、月度 12 个、重要操作 24 个。V1 业务记录 ID 不改变。

## 3. Supabase 表

### 3.1 keypocket_sync_meta
每个用户一行，保存随机 key_salt、PBKDF2 迭代次数和 schema version。盐不是秘密；解锁密码不上传。

### 3.2 keypocket_sync_items
主键为 (user_id, entity_type, entity_id)。记录版本包括 version、device_id、updated_at、deleted_at，加密负载为 AES-GCM {iv,data}。服务端 RPC 使用 SECURITY INVOKER，按当前认证用户执行条件 UPSERT；只有更高版本或同版本但排序更后的 (updated_at, device_id) 可覆盖旧行。

支持类型：key、project。Skills 目前作为项目记录同步。

### 3.3 keypocket_backup_snapshots
按 (user_id,device_id,snapshot_type,period_key) 保存密文快照，支持 daily/monthly/milestone 类型。个人行 RLS 只允许本人访问。

### 3.4 keypocket_devices
保存用户设备 ID、设备标签和最近活动时间；设备 ID 不是身份凭证。

### 3.5 Skill Radar
keypocket_skill_repos 保存公开 GitHub 仓库当前元数据；keypocket_skill_snapshots 保存每日 Stars/Forks 历史。前端匿名只读，采集工作流使用 Service Role 写入。

## 4. 旧数据迁移

1. 保留 V1 原始密钥库与旧表，不原地改密文。
2. 首次 V2 同步先在本地读取旧 keypocket_vault_sync 快照。
3. 使用用户输入的本地解锁密码和旧 envelope 中的 salt/iterations 解密旧快照。
4. 按记录 ID 与 updatedAt 合并，较新的一方优先；不清空本地库。
5. 将合并结果以 V2 逐条密文写入 keypocket_sync_items。
6. 完成云端写入前不删除旧表或旧快照。
7. V2 备份恢复前建立重要操作快照；恢复后把恢复内容重基准为新版本，避免更高版本的旧删除墓碑覆盖用户主动恢复。

## 5. 关键约束
- API Key 明文只在浏览器内存出现；Supabase 的 payload 为客户端加密密文。
- 设备 ID、实体类型、记录 ID、版本与删除时间为同步所需元数据，可能暴露活动关系，不应包含密钥值。
- 删除采用墓碑同步；过期墓碑仍在云端保留用于防止旧设备复活记录。
- 永久删除会在加密 payload 中携带永久删除标记，所有同步设备收到后移除本地数据与回收站条目。
- 服务端不接触本地解锁密码，不保存 GitHub App 私钥。
