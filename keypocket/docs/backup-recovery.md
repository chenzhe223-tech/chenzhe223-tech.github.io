# KeyPocket 自动备份与误删恢复

最后更新：2026-11-02（UTC+8）

## 本地自动快照
- 密钥库解锁后，记录/项目保存通过约 850ms 防抖队列触发快照。
- 初次解锁、每日首次打开、删除前、导入替换前、云备份恢复前等关键节点尝试创建保护快照。
- 快照 payload 由本地 AES-GCM 密钥加密后写入同一 IndexedDB vault。
- 本地历史最多保留约 30 个每日版本；清理逻辑按约 35 天过期。
- 备份中心提供历史快照列表和版本恢复入口；恢复前先写保护快照。

## 误删恢复
- API Key 与项目采用软删除，不立即清除本地加密原记录。
- 同时写入 encrypted tombstone，包含删除时间、恢复期限、版本和删除实体加密内容。
- 回收站默认 30 天可恢复，支持单条恢复、批量恢复与永久删除。
- 过期 tombstone 会在后续解锁/回收站读取时触发原记录清理并标记 expired。
- 删除/恢复状态应同步到其他设备，防止旧设备把已删除记录重新上传。

## 云端加密快照
- 完成 V2 云同步后，每台设备按自然日生成 daily 快照和按月份生成 monthly 归档。
- payload 包含 records、projects 和 deleted/tombstone 信息，使用独立同步口令派生的 AES-GCM 密钥加密。
- 数据库存储 salt、IV、密文、快照类型与计数等非密钥元数据；不上传解锁密码或 API Key 明文。
- daily 保留约 35 天，monthly 保留约 400 天；云备份可供同账号其他设备读取并恢复。
- 云端快照恢复先尝试创建本地保护快照，再解密校验结构、替换本地数据并再次触发 V2 同步。

## 重要限制
本地快照和主库处于同一浏览器 IndexedDB，因此设备丢失、站点数据清理、浏览器资料损坏时可能同时丢失。云端快照要在成功登录、输入正确同步口令并完成至少一次 V2 同步后才会生成；它不是无需配置的后台自动备份。
