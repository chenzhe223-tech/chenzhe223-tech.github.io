隐私与数据说明

By DAVYLAB · 网页版 · 2026 年 11 月 6 日

仅在本机使用

密钥库使用本机密码派生密钥，以 AES-GCM 加密保存 API Key 和项目。复制时，完整密钥会进入系统剪贴板。界面偏好、公开仓库扫描账号和待收录的公开 Skill 使用浏览器本地存储。本机快照与密钥库保存在同一浏览器，清理网站数据前请另存加密备份。

登录与跨设备同步

选择同步时，Supabase 处理邮箱、登录、恢复邮件和会话。浏览器保存登录令牌。客户端使用独立跨设备口令加密同步内容；服务端同时保存账号与设备标识、时间、版本、记录数量等同步元数据。重设邮箱账号密码不能解密旧备份。

公开仓库与网站服务

网站由 GitHub Pages 提供。搜索或扫描会向 GitHub 发送输入的查询词、仓库或公开账号名；请勿将密钥输入搜索框。访问托管与 API 服务时，相应服务会接收处理请求所需的网络信息。

管理数据

在设置中可导出加密文件、恢复备份、查看回收站和退出同步。清除本机数据与退出登录均不会删除云端账户。网页版目前尚未提供自助注销，涉及账号与隐私的问题请通过项目支持入口反馈，勿公开邮箱、密码或密钥。
