# DAVYLAB Writing Quality Engine · P0

状态：Code Completed（仅试点规则模块）；Build / Runtime / Functional / Production 尚未验证。

## 目标
在公众号平台引入可选的“去 AI 味”编辑辅助，不自动覆盖原文，不改变现有生产流程。首批 10 篇历史文章做人工盲评。

## 许可边界
参考 https://github.com/larashero3-dotcom/lieflat-less-ai-tone 的设计思路；在确认授权之前，不复制其 CC BY-NC 4.0 许可代码、词库或训练数据，也不将其作为商业功能直接集成。

## P0 交互
- 输入原文 → 检测重复套话与模板化连接词 → 逐条提示证据和修改方向。
- 三栏：原文 / 建议 / 优化稿；修改稿必须由用户确认后保存。
- 事实、数字、专有名词、引用、来源链接设为保护项；AI 改写后逐项复核。
- 检测分数只是编辑辅助，不声称识别 AI 作者身份。
- 失败时原文仍可编辑、保存和发布；不阻塞既有工作流。

## 验收
1. 10 篇历史文章，覆盖科技、财经、观点和新闻。
2. 对比事实准确、风格保留、可读性、编辑耗时、Token 成本。
3. 任何数字、日期、引文、公司名称发生无依据改变即不通过。
4. 逐项接受/拒绝修改；无静默覆盖、无自动发布。
5. 手机端三栏改为分段切换；不得出现横向溢出。
6. 发布前完成真实构建、功能测试、线上回归，并记录证据。

## 后续
定位公众号平台实际页面和内容生成调用点，接入独立编辑组件。先以只读规则检测起步，随后按授权模型接口实现可选改写。不得把本文件或分支存在视为平台功能已上线。
